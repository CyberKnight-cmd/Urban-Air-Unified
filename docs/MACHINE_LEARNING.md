## 1. XGBoost Extreme Gradient Boosting
Our forecasting engine utilizes XGBoost. XGBoost builds an ensemble of decision trees sequentially, where each tree attempts to correct the residual errors of the previous trees.

### 1.1 Objective Function
The objective function consists of a loss function `L` (evaluating how well the model fits the training data) and a regularization term `Ω` (penalizing complexity).

```text
Obj(Θ) = Σ L(y_i, y_hat_i) + Σ Ω(f_k)
Ω(f) = γT + 0.5λ ||w||^2
```

### 1.2.1 Tree Depth and Regularization Parameter Tuning 1
In hyperparameter optimization phase 1, the maximum tree depth (`max_depth`) was strictly controlled to prevent overfitting on historical air quality variance. Air pollution is highly stochastic due to sudden wind shifts. If the tree depth is too high (e.g., > 10), the model will memorize specific historical pollution events (like a one-off factory fire in 2024) rather than generalizing the underlying meteorological patterns. We applied L2 regularization (`lambda`) to the leaf weights (`w`). This ensures that no single feature (e.g., a sudden spike in Temperature) disproportionately swings the PM2.5 prediction. The learning rate (`eta`) was scaled down to 0.05, requiring more boosting rounds but resulting in a significantly smoother loss convergence curve during the training phase against the historical sensor data.

## 2. Non-Negative Matrix Factorization (NMF) for Source Attribution
NMF is a dimensionality reduction technique. Given a non-negative matrix V (our pollution data), NMF finds two non-negative matrices W and H such that V ≈ WH.

### 2.1 The Factorization Matrix
```python
# Pseudocode representation of the NMF factorization process
from sklearn.decomposition import NMF
import numpy as np

# V: (Samples x Pollutants)
# Pollutants: PM2.5, PM10, NO2, SO2, CO, Benzene, Toluene
V = np.array(historical_data)

# Force 4 components (Traffic, Industry, Biomass, Solvents)
model = NMF(n_components=4, init='nndsvda', max_iter=1000)
W = model.fit_transform(V)
H = model.components_
```

Factor 1 showed isolated spikes in `SO2` and `PM10`, characteristic of industrial coal burning and heavy manufacturing. Factor 2 grouped organic carbon precursors, representing agricultural biomass burning. The non-negativity constraint of NMF is physically crucial here: pollution concentrations cannot be negative.
